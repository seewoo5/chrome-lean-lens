Real Lean (Local Helper)

The helper (node helper/lean-lens-helper.mjs) runs Lean on your machine for the pull request you are reading, so hovers and proof states are Lean's own. It prints its address and token when it starts. Elaborating a file runs the code in it, so Lean only runs when you click Run Lean in a hover, and only on repositories you have allowed. On macOS and Linux that code runs in a sandbox, without access to your files, and with the network only while the project's dependencies are fetched; where there is no sandbox, the helper does not run it unless started with --no-sandbox. Started with --codespaces, the helper runs Lean in GitHub Codespaces on your account instead, and this machine keeps only the results.
